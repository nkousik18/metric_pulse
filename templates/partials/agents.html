AI agents

Three LLM agents built with LangGraph sit on top of the pipeline. Each one is measured by its own eval suite; the scores below are from the latest runs, weak numbers included.

Investigation Action and approvals Onboarding

Investigation agent

Explains an anomalous day: it drills into the segments that moved, writes the cause in plain English, and every number it cites is checked against the data before the answer is shown.

    Action agent

    Proposes a response to an anomaly (annotate it, suppress repeat alerts, notify a segment owner, open an incident, add a watch) with cited evidence and the exact payload. Nothing runs until a person approves, edits or rejects it, and reversible actions can be undone.

    Onboarding agent

    Takes a CSV the pipeline has never seen, classifies its columns (date, metrics, dimensions, what to ignore), and after a person confirms, generates the tables so the same detect, decompose and explain pipeline runs on it unchanged.
